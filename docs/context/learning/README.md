## 3. 使用方式

每个知识点都有稳定编号，例如 `AGL-06-05`。后续可以直接提出：

```text
讲解 AGL-06-05
讲解 ToolCall 截断，并结合项目代码
继续学习第 8 章 MCP
复习已经学过的 Provider 结果未知
```

每个知识点的正式讲解统一覆盖：

1. 概念和解决的问题。
2. 最小协议、数据结构或伪代码。
3. 常见框架实现。
4. PEF 对应代码和真实链路。
5. Demo 实现与生产实现的差异。
6. 故障、安全、事务和并发边界。
7. 自测问题与可选编码练习。

## 4. 深度等级

- `D1 了解`：能准确说明概念、用途和边界。
- `D2 读码`：能跟踪项目代码，解释输入、输出和主要分支。
- `D3 编码`：能独立完成小型实现、测试和故障实验。
- `D4 架构`：能设计生产协议，解释取舍、失败语义和治理边界。

深度由学习者逐点决定，不要求所有知识点都达到 `D4`。
