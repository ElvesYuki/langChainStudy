# 培训网站 V3.3 浅色演讲主题说明

日期：2026-08-05

## 调整目标

V3.2 已完成按内容关系组织的多样化演讲构图，但演讲外壳、部分整页背景和若干大型组件仍使用大面积深蓝。V3.3 在不改变 22 页内容结构、渐进步骤和交互方式的前提下，将演讲模式统一为白色画布与浅蓝灰环境。

## 主要变化

- 全部幻灯片改为浅色页面，不再使用整页深色主题。
- 演讲外壳、页码导航、底部控制栏和演讲者备注改为半透明白色。
- 工具调用、智能体状态、快速判断和总结等大型深色组件改为白色或低饱和浅色。
- 流程节点、模型核心和状态节点使用浅色强调面，不再依赖黑底反白。
- 深色仅保留在工具调用中的小型代码片段，用于区分代码与说明文字。
- 增加自动检查，防止后续重新引入整页深色主题或 `#07101f` 大型背景。
