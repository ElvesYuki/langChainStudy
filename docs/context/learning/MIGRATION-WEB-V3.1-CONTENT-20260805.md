# 培训网站 V3.1 内容增强说明

## 1. 调整原因

V3 的工程结构和视觉表现优于第二版，但演讲内容为了适应整齐卡片而被过度压缩。文章中虽然保留了部分解释，现场演讲页面却失去了任务定义、具体工具参数、部门输入产出和五句话总结等关键信息。

V3.1 保留 V3 的 Next.js、Tailwind CSS、shadcn/ui、MDX 和独立演讲组件架构，以第二版内容作为最低基线重新组织第一章。

## 2. 内容设计原则

- 核心解释直接出现在演讲页面，不藏在演讲者备注中；
- 每个概念同时说明定义、软件位置、贯穿案例和能力边界；
- 机制复杂时增加页面，不把多个关键步骤压进一张五列卡片；
- 所有概念继续沿“报名表 + 访谈记录 → 培训需求汇报”的案例展开；
- 文章与演讲各自适配媒介，但概念口径保持一致。

## 3. 演讲结构

第一章从 16 页扩展为 22 页：

1. 封面；
2. 贯穿案例；
3. 普通对话与智能体软件；
4. AI 应用内部结构；
5. 五概念点击式定位；
6. 上下文形成机制；
7. 上下文容量、相关性和安全边界；
8. 大模型输入、生成过程和输出；
9. 大模型能力与边界；
10. 工具的读、写、改、执行；
11. 具体工具调用、权限检查和返回值；
12. 智能体定义；
13. 智能体任务状态；
14. 判断、行动、观察和更新循环；
15. AI 应用、大模型和智能体关系；
16. 模型、工具、智能体和人的职责边界；
17. 完整可追溯任务链；
18. 失败、停止和人工接管；
19. 完整任务说明；
20. 不同部门的输入与产出；
21. 快速判断；
22. 五句话总结。

## 4. 恢复和新增的重点

- 恢复第二版的完整任务定义页面；
- 恢复 `analyze_spreadsheet`、参数、权限检查、执行状态和具体返回值；
- 恢复各部门场景的输入与产出；
- 恢复对应五个核心概念的结尾总结；
- 新增上下文边界、大模型边界和智能体循环；
- 五概念定位页支持点击切换详细解释。
