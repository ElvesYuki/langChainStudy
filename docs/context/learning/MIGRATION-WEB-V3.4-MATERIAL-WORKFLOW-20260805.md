# 培训网站 V3.4 材料中间表示实践说明

## 1. 调整原因

第一章已经说明目标、上下文、工具权限、产物和验收标准，但尚未把“怎样准备材料”落成可直接复用的工作方法。本次增加个人实践经验，连接概念认知与日常文件处理。

## 2. 核心口径

- 不把“AI 友好”简化为所有文件统一转换成 Markdown；
- 原始 Word、Excel、PDF 继续作为数据、格式和验收依据；
- 叙述性内容优先使用 Markdown 工作副本；
- 精确表格使用 CSV、JSON 或 Excel，计算交给表格工具或程序；
- 图片、扫描件和复杂版式同时保留 OCR 文字与原始文件；
- 中间结论使用 Markdown 或 JSON 组织，最终再生成 Word、Excel 或 PPT；
- 转换可能丢失批注、修订、公式、数据类型和多工作表关系，必须回到原件验收。

## 3. 内容变化

- 阅读文章在“任务定义”之后增加“先转换成适合分析的中间表示”；
- 增加格式选择表、六步工作流、示例目录和转换损失提醒；
- 演讲新增 1 页材料工作流，第一章由 22 页调整为 23 页；
- 新增页面标记为约 1 分 20 秒的实用方法选讲，保持原有概念主线；
- 典型场景和快速判断页编号顺延。

## 4. 状态边界

本次只修改公司培训内容，不更新个人 Agent 工程化学习状态，也不修改 PEF 项目代码、文档、数据库、配置或 Git 状态。
